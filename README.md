Mapster — лёгкий аддон для улучшения карты мира: позволяет менять масштаб и прозрачность карты, двигать окно, показывать координаты игрока и курсора, а также убирать «туман войны» при наличии соответствующего модуля. Карта становится компактнее и удобнее, не перегружая интерфейс лишними функциями.

Настройка выполняется прямо на карте мира: откройте карту клавишей M, используйте кнопки/ползунки аддона для изменения масштаба, прозрачности и отображения координат; дополнительные параметры доступны в меню Интерфейс → Модификации → Mapster. Если «туман войны» не снимается, установите совместимый модуль FogClear и перезапустите интерфейс.
